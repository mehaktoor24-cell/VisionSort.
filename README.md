# VisionSort.
VisionSort is an AI-based waste classification system that uses a Convolutional Neural Network (CNN) model to classify waste images into three categories: Plastic, Metal, and Organic. The project includes a Flask web application where users can upload waste images and get instant predictions.
# VisionSort AI

VisionSort is an AI-based waste classification system that uses a Convolutional Neural Network (CNN) model to classify waste images into three categories:

- Plastic
- Metal
- Organic

## Technologies Used

- Python
- TensorFlow
- CNN
- Flask
- HTML
- CSS

## How to Run

Install requirements:

pip install -r requirements.txt

Run application:

python app.py

Open:

http://127.0.0.1:5000
